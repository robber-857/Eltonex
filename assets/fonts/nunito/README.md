# Nunito

Unmodified variable fonts from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/nunito

- `nunito-variable.ttf`: Nunito[wght].ttf
- `nunito-italic-variable.ttf`: Nunito-Italic[wght].ttf
- `OFL.txt`: SIL Open Font License, bundled with the fonts.

Self-hosted for the About page, including its footer. Other pages keep their existing typography.
